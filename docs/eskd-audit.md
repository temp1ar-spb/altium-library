# Приведение библиотеки к ЕСКД и проверка распиновки

Изменено обозначений: 305, перерисовано УГО: 35, добавлено выводов: 13.

Все изменения внесены скриптами из `script/eskd-tools` без Altium Designer:
файлы .SchLib/.PcbLib читаются и записываются напрямую. Перед записью проверено,
что пересборка неизменённых файлов побайтно совпадает с оригиналом, а повторный
запуск скрипта по обновлённой библиотеке ничего не меняет. Подробный журнал изменений
по каждому компоненту пишет `eskd.py` (`eskd-changelog.json`).

**Перед использованием в проектах откройте библиотеки в Altium и перекомпилируйте IntLib.**

## 1. Позиционные обозначения (ГОСТ 2.710-81)

| Было | Стало | Что |
|---|---|---|
| D? | DA? | аналоговые ИС: ОУ, компараторы, АЦП/ЦАП, питание, драйверы затворов, аналоговые датчики, аналоговые ключи, 74HC4051, AT7456 |
| D? | DD? | цифровые ИС: МК, ПЛИС, логика, интерфейсы, тактирование, цифровые датчики (ICM-42688-P, SPL06-001, LIS2DE12, MAX30102, MAX30205), цифровые SRC (CT5302/CT7302) |
| D? | DS? | микросхемы памяти (устройства хранения информации) |
| D? | A? / U? | модули: A — устройства (ESP-модули, SBC, SoM), U — преобразователи DC/DC и AC/DC |
| B? | GB? | батареи и батарейные держатели |
| J? | X? | перемычки (джамперы) |
| SP* | X? | Solder_Pad |
| TP? | XT? | контрольные точки |
| SW?/SB? | SB? / SA? | кнопки — SB, переключатели и энкодер — SA |
| BF? | HA? | зуммер (звуковой сигнализатор) |
| PT? | FV? | газовые разрядники |
| FL? | Z? | LC-фильтры EMI (EMI_LC_Combined, Murata BNX) |
| FB? | L? | ферритовые бусины |
| Z? | ZQ? | кварцевые резонаторы |

Без изменений: VD, VT, HL, R, RU, C, L, T, K, X, XS, G, U (оптопары), WA, FU.
`NT?` (Net Tie) и `X?` у экранов Laird оставлены: в ГОСТ 2.710 для них нет кода.

## 2. Шрифты

Во всех .SchLib таблица шрифтов приведена к одному шрифту — **ISOCPEUR**
(основной шрифт библиотеки, файл лежит в `fonts/`). Раньше вперемешку использовались
Times New Roman (им рисовались номера и имена выводов у резисторов, транзисторов и др.),
GOST 2.304 type A, GOST type B, GOST2304 Type A. Размеры шрифтов не менялись.

## 3. УГО по ГОСТ 2.743-91 / 2.759-82

Символы в стиле ANSI (треугольники, «пули» логических элементов) перерисованы в стиле,
который уже принят в библиотеке: прямоугольник из трёх полей (5–15–10 мм, шаг выводов 5 мм,
группы разделены линиями), функция — в основном поле.

* **Логика** (`ic-logic`): 13 компонентов — знаки `&`, `1`, `=1`, указатель инверсии
  на инверсных выходах, знак гистерезиса у триггеров Шмитта. У многосекционных ИС
  (HEF4001BT/4093, SN74AUP2G08, SN74AUP3G34, SN74LVC2G132/2G14/2G17/2G34) питание
  вынесено в отдельную секцию; у односекционных питание стоит в левом поле внизу.
  Безымянным выводам питания даны имена из datasheet (VCC/GND, VDD/VSS).
* **Усилители** (`ic-amplifier`, `ic-comparator`, INA18x/19x/282 в `ic-sensor`):
  20 компонентов — знак усилителя в основном поле, питание в правом поле, указатель
  инверсии на инвертирующем входе (у всех ОУ библиотеки, включая уже нарисованные по ЕСКД).
* **Датчики температуры** MCP9700AT, TMP235A2: переведены в прямоугольник.
* **Триггеры**: метка основного поля `D` → `T` (74ALVC74), добавлена `T` у SN74AUP1G74;
  у SN74AUP1G74 добавлен знак динамического входа на CLK; `MUX` у 74HC4051, 74LVC157.
* **Инверсные выводы**: у всех выводов ИС с полностью инверсным именем (`R\`, `O\E\` и т.п.)
  добавлен указатель инверсии (кружок) — 75 выводов.

## 4. Распиновка

### 4.1 Автоматическая сверка УГО ↔ посадочное место

Проверены все 1196 связок «УГО — посадочное место»: номера выводов УГО против номеров
КП на медных слоях (метки 1-го вывода на механических слоях не учитываются).

**Исправлено:**

| Компонент | Проблема | Исправление |
|---|---|---|
| **ESP8266EX** | в УГО не было вывода GND вообще — единственная земля ИС это термопад (вывод 33) | добавлен вывод `0 GND` |
| LTC2204, DRV8353RS, LM5101A, LM5109B, LM4673, nRF52832, MSP432P401M, STM32F401CCU6, STM32F410CBU6, TMC2209, MAX30205 | термопад (КП `0`) есть в посадочном месте, но нет в УГО → EP не получает цепь | добавлен вывод `0 EP` в группу земли |
| посадочное место **8-SOIC-PAD** (`standard-case.PcbLib`) | термопад назывался `" 0"` (с пробелом) → не соединялся с выводом `0` у ADM7150/ADM7151, ADA4898/4899, PN7725 | КП переименована в `0` |
| **AP3417CKTR-G1** | 5-выводная ИС в SOT-23-5 была привязана к SOT23-6 (КП 5 в другом месте!) | посадочное место → SOT23-5 |
| TPS736xxDBV | нет вывода 4 (NR — фиксированные, FB — регулируемые версии) | добавлен вывод `4 NR/FB` |
| CH340G | вывод 12 назывался `DCT` | `DCD`; CTS/DSR/RI/DCD/DTR/RTS — с чертой инверсии, как в datasheet |
| DS90LV047 | имена `DOUT4?`, `DOUT2?` (испорченный символ «−»), `EN*` | `DOUT4-`, `DOUT2-`, `EN` с чертой |
| LM5060 | имя `\P\G\D\` | `PGD` с чертой |
| SPL06-001 | вывод 2 назывался `SCB` | `CSB` с чертой |
| AT45DB041E | RESET, CS, WP без инверсии | с чертой инверсии |
| SN74AUP1G74 | `P\R\E` — черта не над всем именем | `PRE` с чертой |

**Требуют ручной проверки по datasheet (не исправлялось):**

| Компонент | Что не так |
|---|---|
| **SY100ELT23ZG** (PECL→TTL) | выводы 1–4 названы Q0, /Q0, /Q1, Q1, а 6–7 — D1, D0: похоже на копию от ELT22. У ELT23 входы PECL D0,/D0,D1,/D1 на 1–4, выходы TTL Q1,Q0 на 6–7 |
| **HEF4001BT** | имя компонента 4001 (4×ИЛИ-НЕ), а PartNumber, ссылка и УГО — HEF4093BT (4×И-НЕ с триггером Шмитта). Распиновки совпадают; УГО нарисовано как 4093. Нужно переименовать компонент или исправить функцию |
| **AP3429AKTTR-G1** | 5 выводов, но привязано посадочное место SOT23-6 и Package=SOT23-6. Проверить корпус (TSOT-23-5?) |
| **DS3231SN** | выводы 5–12 (N.C.) отсутствуют в УГО; по datasheet они должны быть соединены с землёй |
| **CP2102N** (QFN-28) | нет выводов 10, 13–22 (GPIO.0–GPIO.6 и др.) |
| TS5A3159 | PartNumber = TS5A3166DBVR, Package = SOT-23-5 (у TS5A3159 6 выводов) |
| MAX31865 (TQFN) | нет вывода 17; нумерация похожа на SSOP-вариант — сверить с TQFN |
| MCP73213 | нет выводов 4, 5 и EP |
| LN8323 | нет вывода 7 и EP |
| TEA1791AT | нет выводов 3, 5, 6, 7 |
| 1EDC60I12AH | по памяти: 5=VCC2, 6=OUT+, 7=OUT−, 8=GND2 (в УГО 5=GND2, 6=VCC2, 7=OUT+, 8=OUT−) — сверить |
| LM5060MM | посадочное место `10-TSSOP` не найдено в библиотеке (у ИС корпус VSSOP-10) |
| Connector_microSD_HRS | посадочное место `CON:MICROSD:DM3AT-SF-PEJM5` не найдено |
| W25Q32JV (WSON), AD9744 (LFCSP), ADA4898/4899 | термопад не выведен в УГО; по datasheet его можно не подключать или подключить к −VS/GND — решить по месту |

Остальные несовпадения ожидаемые: крепёжные и экранные КП (MECH, MH, SH, 0 у
разъёмов), выводы NC, которые не показаны в УГО (SOT-23-5 LDO вывод 4, логика
вывод 1 и т.п.), неиспользуемые выводы трансформаторов.

### 4.2 Сверка с datasheet

Сайты производителей из среды, где выполнялась работа, были недоступны (сетевые
ограничения). Поэтому распиновка сверялась по знанию типовых корпусов, а не по PDF.
Проверены все ИС до 24 выводов (≈150 компонентов: ОУ, компараторы, логика, память,
интерфейсы, питание, датчики) и STM32F030/F103/F334/F042/F401/F446. Кроме перечисленного
выше расхождений не найдено. Большие ИС (ПЛИС, BGA-память, МК на 64+ выводов)
по datasheet не сверялись.

## 5. Как повторить

```
pip install olefile
python3 script/eskd-tools/eskd.py library library        # правки ЕСКД (повторный запуск ничего не меняет)
python3 script/eskd-tools/pincheck.py library            # сверка УГО ↔ посадочные места
```
